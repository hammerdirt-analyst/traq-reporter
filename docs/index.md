# TRAQ Reporter

<div class="crumb-bar">
  <span>Home</span>
</div>
<div class="text-block" markdown="1">
TRAQ Reporter turns field tree risk assessments into a clear, client-ready view of each project. 
Built on top of the TRAQ server, the platform supports Tree Risk Assessment Qualification workflows 
with a local demo server, documented deployment paths, container support, and a PostgreSQL-backed 
system for storing project metadata, state, and generated artifacts. The server is designed as an 
operational foundation for capturing assessment data reliably and consistently, while keeping 
completed forms and related outputs organized and accessible.
